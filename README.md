# 内容秒读 · 隐私政策

这个仓库只用来托管 Chrome 扩展「内容秒读」的隐私政策页面，通过 GitHub Pages 公开访问：

- 隐私政策：https://vinsonliangyc.github.io/neirong-miaodu/privacy.html

仓库里不包含扩展源代码。隐私政策和扩展安装包内附带的 `privacy.html` 是同一份内容，扩展的数据处理方式有变化时会同步更新。

This repository only hosts the privacy policy of the Chrome extension "内容秒读" via GitHub Pages. It does not contain the extension's source code.
